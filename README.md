## AI Usage

I have used Claude to decompile my own project and update it to Minecraft 26.3. The reason for this is that, back in 2022, I lost access to the latest development version of the mod, resulting in the loss of more than 50 changes that were still pending commits. Unfortunately, I also lost access to my "y3z0n" GitHub account, meaning I no longer had access to the source code I was working on in 2022. This made me depressed and was ultimately the reason I stepped away from Minecraft modding for several years. Claude was a lifesaver, as it was able to completely reconstruct the source code from the latest development JAR file I had backed up on one of my old Discord servers. I used Claude to accelerate the decompilation and reconstruction process without spending countless hours and energy manually recovering my own work.
AI has not been used to generate any creative assets, including textures, models, or other artwork. I personally commission artists and pay them several hundred US dollars for individual models and textures.
If this kind of AI usage bothers you, please feel free not to use my mod.
